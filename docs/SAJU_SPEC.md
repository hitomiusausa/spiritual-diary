# 四柱推命 計算仕様 v1

更新日: 2026-07-28

## 採用する基準

- 計算エンジンは`lunar-javascript`に一本化する。
- 年柱・月柱・日柱・時柱は、ライブラリの`getEightChar()`を直接利用する。
- 月柱・年柱の境界は、通常の暦月ではなくライブラリが持つ節入りを使う。
- 大運は`getYun(gender, 2)`を使い、起運日・順逆・各10年周期をライブラリの結果から取得する。
- 性別が`female`/`male`以外の場合、大運の順逆を推測しない。
- 出生時刻が空欄の場合は内部計算上12:00を参照値にするが、時柱・時運は参考値として扱い、結果文で出生時刻ありと同じ精度を主張しない。
- 現在の日運・月運・年運・時運はAsia/Tokyoの現在時刻で算出する。

## 現時点で明示する制限

- 出生地はまだ入力しない。現在は日本時間の市民時刻をそのまま使う。
- 真太陽時への補正はまだ行わない。
- したがって、日本国外の出生や、時柱の境界付近の出生は「参考値」として扱う。
- 大運には流派差があるため、現在は採用エンジンの方式を明示して使い、専門家確認で変更できる構造にする。

## 事実と読みの分離

APIレスポンスでは、命式・日運・大運などの計算結果を事実データとして保持する。Kiriの文章はそのデータの解釈であり、次の境界を守る。

- 事実: 柱、日主、五行、起運日、現在の大運、入力された記録
- 読み: 起こりやすい場面、反応の傾向、選択肢、霧の谷からの比喩
- 禁止: 運命の固定化、脅し、病気・投資・法的判断の断定

## 境界ケースの独立照合（2026-07-28実施）

ライブラリ出力を期待値に使う循環参照を避けるため、期待値を古典ルールから独立に導出し、
ライブラリと突き合わせた。導出方法: 日柱=検証済みアンカー（1999-06-07=庚寅)からの
60干支の日送り演算、年柱=公知の干支年、月柱=五虎遁、時柱=五鼠遁。すべて一致した。

| ケース | 内容 | 結果 |
|---|---|---|
| 日柱連続性 | 1900〜2048年の32サンプルで日柱が60干支の日送りと一致 | 一致 |
| 立春前後 | 2024-02-01→癸卯/乙丑、2024-02-08→甲辰/丙寅（立春2024-02-04で年柱・月柱が切替） | 一致 |
| 月の節入り | 2024-06-01→己巳月、2024-06-10→庚午月（芒種2024-06-05で切替） | 一致 |
| 0時の日替わり | 1988-02-15 23:30→日柱庚子、1988-02-16 00:30→日柱辛丑 | 一致 |
| 夜子時 | 23時台の時柱は翌日の日干から起算（23:30と翌00:30がともに戊子） | 一致 |
| 時柱の境界 | 08:59→庚辰、09:00→辛巳、10:59→辛巳、11:00→壬午（奇数時で切替） | 一致 |

### 確認された流派上の採用方式（2026-07-28 プロダクト仕様として承認済み・D-10）

- **日柱の切り替え**: 0時（子正）切替。23時台は当日の日柱のまま。
- **夜子時**: 23時台の時柱は翌日の日干から起算する（子初からの晩子時方式）。
- **大運**: `getYun(gender, 2)`。節入りベースの起運換算、性別と年干で順逆を決定。

### 独立照合でカバーできていないもの

- 節入りの「当日・分単位」の境界（立春当日の切替時刻そのもの）は、外部の暦データとの
  分単位照合が未実施。前後1日以上のブラケットまで確認済み。
- 真太陽時・出生地補正は未実装（v1の制限どおり）。
