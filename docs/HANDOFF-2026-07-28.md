## 1. プロダクトの前提

Kiriは、生年月日を基準にした四柱推命と、その日の心身の記録を組み合わせる日記アプリです。無料の基本体験は「記録 → 命式・今日の運勢 → Kiriの読み解き → 履歴保存」。Kiriとの自由な会話は有料オプションとして想定しています。

Kiriの表現は、やわらかく温かく、少し神秘的。ただし結果を曖昧な雰囲気だけで終わらせず、色・数字・方角・距離感などのキーワードと、記録や上位テーマに結びつく具体的な説明を二段構えで出します。断定・脅し・医療/金融/法的判断はしません。

## 2. 現在動く範囲

```text
基本情報（保存・復元）
  → 日記（気分・出来事・直感）
  → /api/analyze
       ├─ lunar-javascriptで四柱・日/月/年/時運・大運
       ├─ バイオリズムとテーマ別スコア
       ├─ 今日のヒント（安定したシードで選択）
       └─ AnthropicでKiriの3文脈を生成
  → 結果画面
       ├─ 端末内の占い履歴（最大30件）
       └─ Kiriチャット開発プレビュー
            └─ /api/chat + チャット履歴（最大40メッセージ）
```

主要ファイル:

- `src/components/SpiritualDiary.jsx`: 画面遷移、入力、結果、履歴、課金案内
- `src/components/KiriChatPanel.jsx`: 結果画面から開くチャットUI
- `src/app/api/analyze/route.js`: 入力検証、計算、ヒント、AI分析、分析キャッシュ
- `src/app/api/chat/route.js`: 占い結果を文脈にしたKiriチャット
- `src/lib/saju.js`: 四柱推命計算の純粋関数
- `src/lib/kiriPersonality.js`: チャット/占い共通のKiri人格定義
- `src/lib/history.js`, `src/lib/chatHistory.js`: localStorage保存
- `docs/SAJU_SPEC.md`: 採用計算基準と既知の流派差
- `docs/DECISION_INPUT_MAP.md`: 各入力がどの結果に影響するか

## 7. 注意点

- `Documents/Playground/kiri-chat`は、自由チャット版Kiriの検証用プロトタイプ。本体と無計画に統合しない。
- 現在の履歴は端末内localStorageのみ。アカウント間同期やバックアップは未実装。
- 出生時刻なしの場合、内部では12:00を参照値にするが、時柱・時運の精度を出生時刻ありと同じように扱わない。
- 本番用の秘密鍵をクライアントへ出さない。APIエラーはクライアントに詳細を返さない方針を維持する。
