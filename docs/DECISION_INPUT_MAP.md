# Kiriの判断材料マップ

更新日: 2026-07-27

この資料は、同じ結果を再現したいときに「何が判断の拠り所になっているか」を確認するためのものです。

## 全体の考え方

Kiriの結果は、次の4層を順番に重ねています。

1. 生年月日・出生時刻・性別から、本命の命式と大運を計算する
2. 今日の日付・時刻から、今日の四柱（日運・月運・年運・時運）を計算する
3. バイオリズム、気分、記録、直感から「今日の状態」をつくる
4. Kiriが計算結果と今日の記録を、断定しない具体的な言葉へ翻訳する

## 入力と結果の対応

| 判断対象 | 主な根拠 | 変化する条件 |
| --- | --- | --- |
| 本命の四柱 | 生年月日、出生時刻 | 基本情報を変えたとき。出生時刻なしは12:00概算 |
| 大運 | 本命の四柱、性別、現在の日本年 | 性別または出生情報、年が変わったとき |
| 今日の四柱 | 現在の日本日付・時刻 | 日付が変わったとき。時運は時刻でも変化 |
| バイオリズム | 生年月日、現在日 | 生年月日または日付が変わったとき |
| テーマ別運勢 | 本命の日柱、今日の日柱、バイオリズム、気分、出生時刻の有無 | その日の入力を変えたとき |
| 今日のヒントのキーワード | 今日の日柱の五行・十二支、バイオリズム、テーマ平均 | 日付、バイオリズム、気分などが変わったとき |
| 今日のヒントの説明 | ヒントのキーワード、今日の記録、最も高いテーマ | 記録・日付・状態が変わったとき |
| 「Kiriが映すあなたのエネルギー」 | 本命・今日の四柱、大運、バイオリズム、テーマスコア、気分、記録、直感 | 上記のいずれかを変えたとき |
| 「あなたの直感から読み取ったメッセージ」 | 直感、記録、バイオリズム、命式 | 上記のいずれかを変えたとき |
| 「Kiriからのアドバイス」 | テーマスコア、記録、直感、命式、今日の状態 | 上記のいずれかを変えたとき |

## 今日のヒントの内訳

`src/app/api/analyze/route.js` の `calculateTodayHints()` がルールベースで生成します。AIがキーワードを決めているわけではありません。

### 色

- 今日の日柱の天干から五行（木・火・土・金・水）を取得
- バイオリズム3項目の平均が高いと明るい候補、低いと深い候補、中間なら中間色を選ぶ
- 説明文では、今日の記録と最も高いテーマを使ってKiriの言葉にする

### 数字

- 今日の日柱の十二支を独自の1〜9対応表へ変換
- 感情・身体・知性の強弱で1つずつ補正
- 説明文では、数字を「候補を絞る」「呼吸する回数」など小さな使い方へ翻訳する

### 方角

- 今日の五行を東・南・中央・西・北へ対応
- バイオリズムによって一部を南東・南西・北東・北西へ補正
- 実際に移動する指示ではなく、視線や意識を戻す方向として説明する

### 距離感

- 恋愛・お金・仕事・健康のテーマスコア平均を5段階に分類
- 平均が高いほど近い距離、低いほど休む/離れる距離の候補を選ぶ
- キーワードと説明文は同じ候補ペアから選び、意味がずれないようにする

## 再現性のルール

- ヒントの候補選択は入力値から作ったシードを使うため、同じ条件では同じ候補になる
- 分析APIは、日本日付・基本情報・バイオリズム・記録・直感・モデルをキーに結果をキャッシュする
- Anthropic APIには`temperature: 0`を指定する
- したがって、同じ人物・同じ日本日付・同じ入力内容では、同一プロセス中は同じ分析結果を返す
- サーバー再起動後も命式・スコア・ヒントのキーワードは再計算できるが、AI文章まで完全に同じにするには永続的な結果保存が必要

## 注意点

- 出生時刻なしの場合、命式は12:00を参照値として計算し、時柱・時運は精密値として扱わない
- 出生地、真太陽時、流派差は現在の仕様に含めていない
- 四柱推命やヒントは、医療・金融・法律の専門判断ではない
- 「同じ人物」でも、記録や直感を変えた場合は、その日の問いが変わったものとして文章結果が変化する
